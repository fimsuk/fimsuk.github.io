Kebijakan Privasi — Begitu Yea Tim

Berlaku sejak 1 November 2026.

Siapa kami

"Begitu Yea Tim" adalah aplikasi internal milik pemilik channel Begitu Yea. Aplikasi ini dipakai hanya oleh pemilik channel untuk mengelola akun media sosialnya sendiri.

Data yang diakses

  • YouTube Data API: mengunggah video, menjadwalkan, dan membaca data channel milik pemilik.
  • YouTube Analytics API (baca saja): membaca jumlah tayangan dan retensi video milik pemilik untuk laporan internal.
  • Google Sheets API: membaca dan menulis spreadsheet antrean konten milik pemilik.
  • Gmail API (kirim saja): mengirim email notifikasi ke alamat pemilik sendiri.
  • Meta (Facebook, Instagram, Threads): memublikasikan konten dan membaca statistik akun milik pemilik.

Cara data digunakan dan disimpan

Data hanya dipakai untuk menjadwalkan, mengunggah, dan memantau konten Begitu Yea. Token akses disimpan secara lokal di komputer pemilik. Data tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dipakai untuk iklan. Video disimpan sementara di penyimpanan privat dan dihapus setelah tayang.

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use. Penggunaan YouTube API tunduk pada Ketentuan Layanan YouTube dan Kebijakan Privasi Google.

Layanan API YouTube

Aplikasi ini menggunakan YouTube API Services. Dengan memakai aplikasi ini, pengguna setuju untuk terikat pada Ketentuan Layanan YouTube. Informasi tentang cara Google menangani data ada di Kebijakan Privasi Google.

Penyimpanan dan penghapusan data

Aplikasi ini tidak memakai cookie dan tidak menyimpan apa pun di perangkat orang lain. Data dari YouTube (ID video, judul, dan angka statistik) hanya disimpan di spreadsheet pribadi pemilik dan di komputer pemilik, diperbarui setiap hari, dan dihapus paling lambat 30 hari setelah akses dicabut. Pemilik dapat meminta penghapusan semua data kapan saja lewat email kontak di bawah.

Menghapus akses

Akses dapat dicabut kapan saja lewat halaman izin keamanan akun Google dan Integrasi Bisnis di pengaturan Facebook.

English summary

"Begitu Yea Tim" is an internal tool used only by the owner of the Begitu Yea channel to upload, schedule, and monitor videos on the owner's own YouTube channel and social accounts. It uses YouTube API Services; by using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies. Data accessed: the owner's channel data, video uploads, and analytics (views, retention). Data is stored only on the owner's computer and private spreadsheet, is never sold or shared with third parties, uses no cookies, and is deleted within 30 days after access is revoked. Access can be revoked at Google security settings. Contact: begituyea.kontak@gmail.com.
