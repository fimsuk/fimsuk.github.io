Kebijakan Privasi — Begitu Yea Tim

Berlaku sejak 1 November 2026.

Siapa kami

"Begitu Yea Tim" adalah aplikasi internal milik pemilik channel Begitu Yea. Aplikasi ini dipakai hanya oleh pemilik channel untuk mengelola akun media sosialnya sendiri.

Data yang diakses

  • YouTube Data API: mengunggah video, menjadwalkan, dan membaca data channel milik pemilik.
  • Google Sheets API: membaca dan menulis spreadsheet antrean konten milik pemilik.
  • Gmail API (kirim saja): mengirim email notifikasi ke alamat pemilik sendiri.
  • Meta (Facebook, Instagram, Threads): memublikasikan konten dan membaca statistik akun milik pemilik.

Cara data digunakan dan disimpan

Data hanya dipakai untuk menjadwalkan, mengunggah, dan memantau konten Begitu Yea. Token akses disimpan secara lokal di komputer pemilik. Data tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dipakai untuk iklan. Video disimpan sementara di penyimpanan privat dan dihapus setelah tayang.

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use. Penggunaan YouTube API tunduk pada Ketentuan Layanan YouTube dan Kebijakan Privasi Google.

Menghapus akses

Akses dapat dicabut kapan saja lewat pengaturan izin akun Google dan Integrasi Bisnis di pengaturan Facebook.
